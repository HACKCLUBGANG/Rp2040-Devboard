# Rp2040-Devboard
This is a rp2040 chip powered devliopment board with alot  of  gpio pins to  control different modules
It has usb  c, flash  memory, onboard led, 40 total pins, rp2040 microcontroller
It can be easily used in projects.

# How
The rp2040  reads  the flash memory and runs the code given on it and performs tasks written in the code.
The  cystal oscillator proivides clock signals.
The usb c  is connected  a device which  can upload code to  the devlopment board
